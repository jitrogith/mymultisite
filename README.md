## Admin content editor

The public homepage content is managed at `/admin` by an authenticated administrator.
Before creating the initial administrator, configure `ADMIN_USERNAME` and
`ADMIN_PASSWORD` in `.env` (use a unique password of at least 12 characters), then run:

```bash
php artisan migrate --force
php artisan db:seed --class=AdminUserSeeder --force
```

The password is hashed before it is stored. Admin credentials belong in `.env` or
your deployment secret manager, never in source control. The editor currently manages
the homepage identity, contact information, hero text, announcement, services, news,
agenda, and transparency/footer copy.

Use **Page Builder** in the admin panel to create additional public pages. Pages can be
saved as drafts or published at `/halaman/{slug}`. The builder supports headings,
paragraphs, quotations, and lists. Open **VEditor** to arrange visual components such
as text, images, videos, buttons, dividers, spacers, and Google Maps location links.
Heading components include Content, Style, and Advanced settings for links, typography,
layout, backgrounds, and borders. Backgrounds can use a color or an uploaded JPG, PNG,
or WebP image (up to 5 MB). Run `php artisan storage:link` to make uploaded images
available to the public website. The Advanced settings also include per-component
desktop, tablet, and mobile visibility controls plus a plain Custom CSS editor. In
Custom CSS, use `selector` to target the component, for example
`selector { color: #252f60; }`. Page-level layout settings let you stretch content
to the available window width or choose a custom maximum width from 320 to 1920 px.
Published pages are linked from the public navigation. The homepage is managed
separately and cannot be deleted from Page Builder.

Laravel is a web application framework with expressive, elegant syntax. We believe development must be an enjoyable and creative experience to be truly fulfilling. Laravel takes the pain out of development by easing common tasks used in many web projects, such as:

- [Simple, fast routing engine](https://laravel.com/docs/routing).
- [Powerful dependency injection container](https://laravel.com/docs/container).
- Multiple back-ends for [session](https://laravel.com/docs/session) and [cache](https://laravel.com/docs/cache) storage.
- Expressive, intuitive [database ORM](https://laravel.com/docs/eloquent).
- Database agnostic [schema migrations](https://laravel.com/docs/migrations).
- [Robust background job processing](https://laravel.com/docs/queues).
- [Real-time event broadcasting](https://laravel.com/docs/broadcasting).

Laravel is accessible, powerful, and provides tools required for large, robust applications.

Laravel has the most extensive and thorough [documentation](https://laravel.com/docs) and video tutorial library of all modern web application frameworks, making it a breeze to get started with the framework.
